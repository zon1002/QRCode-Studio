# QRBarcode Studio（Rust 版）

Rust / egui 的 QR Code 與條碼產生、標籤列印工具（v4.1.0）。
由 C# 版（v3.1）與 Python 版（v2.14）融合而來：保留兩者有用的功能、修掉已知的缺點，並新增標籤與紙張排版、一頁多格的列印、設定與範本的保存。

**安裝時不需要任何額外套件**：單一 `QRBarcodeStudio.exe`，C 執行環境靜態連結，不需要安裝 .NET、Python 或 Microsoft Visual C++ 可轉發套件。
QR Code 與所有條碼的編碼器都是自己用 Rust 寫的，沒有使用第三方的條碼套件。字型從系統載入、不內嵌；只支援 Windows 10／11 x64。
介面有繁體中文與英文兩種，依 Windows 的顯示語言自動選擇，見〈介面語言〉。

這個 repo 只放使用說明與授權文件，不含原始碼；安裝檔與執行檔請到 [Releases](https://github.com/zon1002/QRCode-Studio/releases/latest) 下載。

## 安裝

| 檔案 | 說明 |
|------|------|
| `QRBarcodeStudio_Setup_v4.1.0.exe` | 安裝程式（建議）；可選桌面捷徑與 `.qrbjob` 檔案關聯 |
| `QRBarcodeStudio.exe` | 單一執行檔，不用安裝就能執行；沒有開始功能表捷徑，也不會登記 `.qrbjob` 檔案關聯 |

- 程式沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」；確認檔案是從上面的 Releases 下載的，按「其他資訊」→「仍要執行」即可。
- **預設只裝給目前的使用者，不需要系統管理員權限**；安裝時也可以改成裝給這台電腦的所有使用者。
- 安裝後有開始功能表捷徑，包括「使用說明 (README)」、「授權條款 (License)」與「第三方元件授權」；桌面捷徑可以選擇要不要建立。
- **安裝程式的語言**依 Windows 的顯示語言自動選擇（繁體中文或英文，不會問語言）；開始功能表的捷徑名稱與「使用說明 (README)」開啟的檔案（`README.md` 或 `README.en.md`）也跟著安裝程式的語言。
- **`.qrbjob` 檔案關聯**（預設勾選）：把 `.qrbjob` 列印檔交給本程式開啟，在檔案總管雙擊列印檔就會打開本程式並載入它。
- **程式已經開著時，再雙擊列印檔會開第二個視窗**，不會把檔案送到原本的視窗。
  **第二個視窗改的設定不會儲存**（紙張預設、標籤格式、主題、版面等），啟動時狀態列會寫「另一個 QRBarcode Studio 視窗已經開著，這個視窗改的設定不會儲存；範本與列印檔照常儲存」；範本與列印檔是各自的檔案，照常儲存。
  這樣兩個視窗不會互相蓋掉對方改的設定（例如在一個視窗新增的紙張預設，被另一個視窗關閉時蓋掉）。要改設定，請在先開的視窗改，或把所有視窗都關閉後再開程式。
  先開的視窗在設定資料夾裡開著 `instance.lock`，程式結束時（包括當掉）由 Windows 放開。
- **解除安裝會保留設定與範本**：只移除程式本身，`%APPDATA%\QRBarcodeStudioRS\` 不會被刪除；要完全清除請自己刪掉這個資料夾。
- 安裝新版會直接覆蓋舊版，設定與範本照舊。

## 功能

全域切換「QR Code」與「條碼」兩種模式，切換時兩邊各自的設定都會保留。
參數一改，預覽就自動更新（背景產生並防抖，打字時畫面不會卡住）；欄位填錯時，錯誤直接顯示在欄位旁，不跳出視窗。

### QR Code

- **內容類型 14 種**：純文字、網址、Wi-Fi、vCard 名片、Email、簡訊 SMS、電話、地理位置、日曆事件、Bitcoin、TOTP、Skype、MMS、書籤。
  每種都依規範處理特殊字元（Wi-Fi、vCard、日曆的跳脫，Email 的百分比編碼等）；網址格式不對時會提示，但不阻擋。
- **編碼**：版本 1–40，容錯等級 L／M／Q／H（預設 M），數字、英數、位元組（UTF-8）三種模式，自動切分成最短的混合模式，自動挑選遮罩。
- **造型**：模組形狀 6 種（方塊、間隔方塊、圓點、圓角、直條、橫條）；顏色模式 6 種（純色、放射漸層、方形漸層、水平漸層、垂直漸層、底圖上色）；前景色、背景色、漸層第二色。
  選了「底圖上色」卻沒有載入底圖時，欄位旁會說明，不會默默改成純色。
- **中心 Logo**：大小 10–40%（建議 25%）、圓角、底框與底框顏色。載入 Logo 時，只有在你沒有手動按過「容錯等級」的情況下才自動改成 H；移除 Logo 不會自動改回。

### 條碼

- **類型 19 種**：
  - 一維 12 種：Code 128、GS1-128、Code 39、Code 93、EAN-13、EAN-8、UPC-A、UPC-E、ITF、ITF-14、Codabar（NW-7）、PZN。
  - EAN-13 的衍生類型 4 種：ISBN-13、ISBN-10、ISSN、JAN（輸入轉換加驗證，轉成對應開頭的 EAN-13）。
  - 二維 3 種：Data Matrix、PDF417、Aztec。
- **輸入即時驗證**：位數、校驗碼、允許的字元、偶數位（ITF）等，錯誤顯示在欄位旁；GS1-128 用括號標示 AI，例如 `(01)04712345678900(17)261231`。
- **參數**：模組寬、條高、靜區、上方與下方留白（一維條碼的上下不算靜區，預設 0 mm）、前景色與背景色、條碼下方的文字（字級與間距）、二維碼的字元集、EAN／UPC 的長護線。
- 每種類型可以輸入什麼、範例與建議靜區，都寫在說明視窗（F1）的「條碼類型一覽」，那張表是從程式本身產生的。

### 附加文字

QR Code 與條碼共用同一套樣式：文字來源（手動輸入或資料的某一欄）、系統字型、字級（pt，0 為自動）、顏色、對齊、位置（下、上、左、右）、上下間距。
文字太寬時最多折成 N 行（預設 2 行），並逐步縮小字級到最小值（預設 6 pt）；背景和條碼的背景色相同。
「寫入 QR 編碼內容」預設關閉，只有內容類型是「純文字」時才能勾選。所有輸出格式都會畫出附加文字，向量格式（SVG、PDF、EPS）把文字轉成外框，不依賴對方電腦有沒有那個字型。

### 資料來源

所有來源都填進同一份資料清單，批次輸出與列印用的是「目前載入的清單」，不是目前顯示的分頁。

- **手動輸入**：表單輸入，一筆。
- **多行貼上**：一行一筆。
- **序號**：依規則產生，例如 `A-0001~A-0100`；前綴與後綴可以是空的，依起點的位數補零，可設間隔；超過 10 萬筆會先請你確認。
- **檔案**：
  - Excel（xlsx、xls、xlsm、ods）：可選工作表、可勾選「第一列是標題列」；Excel 正開著同一個檔案時也讀得到。
  - CSV：自動偵測編碼（UTF-8（含 BOM）、UTF-16、Big5／CP950）與分隔符號（逗號、Tab、分號），正確處理引號與欄位內換行。
  - 所有值都以文字讀取：整數不會出現 `.0`、空白格是空字串、日期是 `yyyy-MM-dd`。
- **欄位對應**：多欄位的 QR 類型（Wi-Fi、vCard、Email 等）批次時，每個欄位可以對應到資料的某一欄、填固定值，或留空；附加文字與「數量欄」也一樣。
  對應以欄名記在範本與列印檔裡，下次載入欄名相同的檔案時自動套用，對不上的欄名會列出來讓你重新對應。
- **資料表**：10 萬筆仍可順暢捲動，無法產生的筆與數量有問題的筆會標出來；「輸出範圍」可以只輸出第 N 到第 M 筆，每個資料來源各自記錄。

### 輸出

- **單張**：PNG、JPEG（品質 10–100）、WebP（無損）、BMP、SVG、PDF、EPS、TXT（ASCII 字元畫或 Base64）；依存檔時輸入的副檔名決定格式。
  點陣格式會寫入 DPI；在預覽圖上按右鍵可以複製圖片（ASCII 與 Base64 是複製文字）。
- **尺寸**有兩種指定方式：「依模組」指定模組大小；「指定外框」指定整張圖的寬或高（含靜區與附加文字），指定的寬或高就是整張圖實際的寬或高，條碼在裡面置中，不會被拉長或壓扁。
  存成點陣圖與列印時，每個模組都對齊整數個點，不會有灰色的模糊邊；預覽旁會顯示實際尺寸與模組大小。
- **批次匯出**：在背景執行、顯示進度、可以隨時停止。
  - 檔名規則：`{index}`、`{index:04}`（補零位數）、`{value}`、`{caption}` 與 `{欄名}`；不合法的字元換成 `_`。
  - 同名檔案：「自動加編號」（預設）、「略過」或「覆蓋」，開始前先告訴你有幾個衝突。
  - 單筆失敗不會中斷整批；結束後列出成功數、失敗數與失敗清單，清單可以匯出成 CSV。
  - 也可以「依版面合併成一個 PDF」，用「版面」的設定排成一頁多格。

### 版面與列印

- **紙張**：一般紙張（A3、A4、A5、B4、B5 等）、Brother DK 連續標籤帶（寬 12、29、38、50、54、62 mm，長度可設）、DK 模切標籤（10 種），共 24 項；可以新增、修改、刪除。
  5 種 A4 標籤貼紙格式（3×8、3×7、2×7、4×10、5×13）一次套用紙張、格子、邊界與格距，自己常用的格式可以另存。
- **格子**：欄數×列數或指定單格大小、邊界、水平與垂直格距、起始格（用過一部分的貼紙可以接著印）、裁切框線、單格內容的排列。
- **張數與份數**：每筆張數（也可以用「數量欄」讓每筆印不同張數）、填滿整頁（每筆從新的一頁開始並印滿）、列印份數。
- **列印**（Windows GDI）：列出所有印表機並預選系統預設印表機；紙張優先比對驅動程式自己的紙張清單，找不到才用自訂尺寸，都不行時列出驅動程式的紙張讓你挑；整個工作是一個列印工作，可以只印某幾頁。
  印出來的實際大小等於設定的 mm，並扣除印表機實體不可列印的邊。
- **預覽列印**：顯示真正送到印表機的影像，畫出不可列印的邊與 mm 尺規，可以先核對位置與大小。「依版面合併成一個 PDF」輸出和列印相同的排版，PDF 頁面尺寸就是設定的 mm。
- 預覽、存檔、批次、整頁預覽、合併 PDF 與列印都經過同一條路徑，看到的、存下的、印出的是同一個東西。

### 範本與設定

- **範本**：存下完整的設計、版面、輸出設定、欄位對應、每筆張數、填滿整頁、份數；不含資料本身。
  每個範本是一個 `.json` 檔，可以匯入與匯出；Logo 與底圖以 base64 內嵌，複製到別台電腦也能用；某個範本損毀時只略過那一個。
  內建 6 個範本：62×29 商品標籤、A4 24 格貼紙、Wi-Fi 分享、名片 vCard、EAN-13、網址 QR，可以修改或刪除。
- **設定**：記住目前的版面（E 或 C）與停留的頁面、視窗位置與大小、主題（亮色／暗色）、上次的產生參數、最近開過的資料檔、上次的輸出資料夾與紙張預設。
- **列印檔的鎖**：程式本身沒有密碼；要把列印檔交給同事又不想被改時，存檔時可以鎖住「內容」「資料來源」「附加文字」「樣式」「版面」中的幾項並設一個密碼，見〈列印檔的鎖〉。

### 說明

按 F1 或狀態列最右邊的「說明」，打開「QRBarcode Studio 說明」視窗，左邊是主題清單、右邊是內容；兩套版面都能用。
說明裡容易和程式不一致的內容（條碼類型、範例與建議靜區、內容類型、快捷鍵、列印檔的鎖）都從程式本身產生。主要欄位都有滑鼠提示，所有捲動區都可以用滑鼠滾輪。

## 兩套版面

兩套版面共用同一份設定、資料與範本，切換時不會遺失任何輸入。上方工具列的最右邊都有「E 版面」「C 版面」兩個按鈕，目前的版面是選中的；按另一個就立即切換，不需要重開程式，也不需要密碼。第一次開啟是 E 版面，之後回到上次的版面。

| 代號 | 名稱 | 給誰用 | 說明 |
|------|------|--------|------|
| E | 側邊導覽列 | 自己日常使用 | 左邊依工作順序排列「檔案」「資料」「內容」「樣式」「文字」「版面」「輸出」，最下面是「範本」「設定」；右邊是即時預覽，可以切換單張與整頁 |

## 介面語言

介面有繁體中文與英文兩種。語言在程式啟動時依 Windows 的「顯示語言」決定一次，不需要設定，也沒有切換按鈕：

- 顯示語言是**繁體中文**（台灣、香港、澳門）時，介面是繁體中文。
- 顯示語言是其他語言（包括簡體中文與日文）時，介面是英文。
- 想在中文的 Windows 上看英文版（或反過來）時，用環境變數 `QRBARCODE_LANG` 指定：值是語言標籤，例如 `en`、`en-US`、`zh-TW`、`zh-Hant`，不分大小寫；空字串或不認得的值會被忽略，照 Windows 的語言。
  在 PowerShell 用英文啟動：`$env:QRBARCODE_LANG = "en"; .\QRBarcodeStudio.exe`；在命令提示字元則先執行 `set QRBARCODE_LANG=en`，再從同一個視窗啟動程式。

整個介面都跟著語言：畫面、說明視窗、錯誤訊息、預覽列印，以及批次匯出的結果（含失敗清單 CSV 的表頭）。數字、日期與單位（mm、pt、dpi）不變。
設定、範本與列印檔在兩種語言之間通用：在一種語言存的列印檔，換另一種語言開啟時，欄位對應、內建紙張與附加文字的字型都照常運作。
內建的紙張、標籤格式與範本在第一次執行時用當時的語言命名並存起來，之後換語言不會改名，也不會多出重複的項目。

## 列印檔

列印檔（副檔名 `.qrbjob`）把「這一次的列印工作」存成檔案，之後可以原樣重印，也可以拿到別台電腦或給同事開。在「檔案」標籤（C 版面是「檔案與列印」）按「開啟檔案…」「儲存檔案…」。

- **存了什麼**：設計（含 Logo 與底圖）、版面、輸出設定、欄位對應、每筆張數、填滿整頁、份數、資料來源與輸出範圍，以及印表機、紙張與頁面範圍；有鎖的話，還有鎖住的部分與密碼的雜湊值。
- **資料來源是多行貼上或序號時**，貼上的內容或序號規則直接存在列印檔裡；**Excel 與 CSV 只記下檔案的路徑與匯入設定**，開啟時重新讀取，所以資料檔改過的話，印出來的是新的內容。
- **找不到資料檔時**：先找記下的原本路徑，再找列印檔所在資料夾裡同檔名的檔案；都找不到時顯示原本的檔名與路徑，請按「瀏覽…」找回來。找到之前不能預覽、列印或輸出，以免印到不對的資料。把列印檔和資料檔放在同一個資料夾，搬到別台電腦時也找得到。
- 有未存的修改時，視窗標題會加上「*」，開啟別的列印檔或關閉程式前會問要不要儲存。
- 在檔案總管雙擊列印檔就會開啟（見〈安裝〉的 `.qrbjob` 檔案關聯）。
- 存檔時可以鎖住列印檔的某些部分，見下一節〈列印檔的鎖〉。

## 列印檔的鎖

程式本身沒有密碼，鎖跟著列印檔走：自己用的列印檔不鎖、不用密碼；要把列印檔分享給同事時，才在那一份檔案上決定鎖什麼、設密碼。
鎖是防止同事不小心改掉版面或樣式，不是資安防護：輸入密碼的次數不限，會用記事本改列印檔的人也能拿掉它（見〈忘記列印檔密碼〉）。

### 怎麼設

1. 按「儲存檔案…」（或 Ctrl+Shift+S；還沒有列印檔時，Ctrl+S 也一樣），先出現「儲存列印檔」視窗。已經開著列印檔時，Ctrl+S 直接存回去，不出現這個視窗，鎖與密碼原樣保留。
2. 勾選「鎖定後分享給別人」。預設不勾：不勾就不鎖，也不用密碼，和一般存檔一樣。
3. 勾了之後，選要鎖的部分：「鎖定內容」「鎖定資料來源」「鎖定附加文字」「鎖定樣式」「鎖定版面」，預設勾「鎖定版面」與「鎖定樣式」，至少要勾一項；各部分分開鎖，例如鎖了「樣式」，「附加文字」仍然可以改。
4. 輸入「密碼」與「再輸入一次密碼」。密碼空白或兩次不一樣時，欄位下方會說明原因，視窗不會關閉。密碼以 Argon2id 加鹽雜湊存在列印檔裡，不存明碼。
5. 按「繼續」才開存檔對話框；按「取消」什麼都不存。

### 鎖住什麼

| 部分 | 變灰、不能修改的項目 |
|------|------|
| 內容 | 「內容」標籤的內容類型與輸入欄位（條碼是「條碼內容」與 EAN／UPC 的「附加碼」），以及「寫入 QR 編碼內容」 |
| 資料來源 | 「資料」標籤的資料來源選擇（手動輸入、多行貼上、序號、檔案）、選檔、工作表、欄位對應、輸出範圍與序號規則 |
| 附加文字 | 「文字」標籤（C 版面是「附加文字設定」）的全部設定 |
| 樣式 | 「樣式」標籤（C 版面是「樣式設定」）的全部設定，加上工具列的「QR Code」「條碼」切換，以及「內容」標籤裡的條碼類型與編碼選項（容錯等級、最小版本、校驗字元、Full ASCII 等），因為這些都會改變條碼的大小與外觀 |
| 版面 | 「版面」標籤（C 版面是「版面設定」）的 A4 標籤貼紙格式、紙張設定、格子與單格排列 |

- **欄位對應的每一列**跟著它所屬的部分：內容欄位的列屬於「內容」，附加文字的來源列屬於「附加文字」，數量欄只屬於「資料來源」；那一列所屬的部分或「資料來源」有一個鎖住，就不能改。
- **「寫入 QR 編碼內容」**：勾選時，附加文字會一起編進 QR Code，成為掃描出來的內容的一部分；要讓掃描出來的內容不被改，除了「內容」，也要鎖「附加文字」。
- **永遠不鎖**（同事一定要能印）：「檔案」標籤的印表機、份數、頁面範圍、「預覽列印…」「列印」與「改用印表機的紙張」，「版面」標籤的「張數」區與「起始格」，「輸出」標籤與批次匯出，「設定」標籤，以及找不到資料檔時的「瀏覽…」、記錄的工作表不見時的「要用的工作表」、開啟時取消產生序號後的「重新產生序號」。
- **套用範本**（E 版面的「範本」標籤、C 版面工具列的「範本」選單）：只要有任何一部分鎖著就停用，說明「這個列印檔有鎖定的部分，不能套用範本。」，因為範本會換掉整個設計、欄位對應與版面。另存、匯出、匯入與刪除範本不受影響。

### 同事打開有鎖的列印檔

- 被鎖的部分在 E、C 兩套版面都是灰色的，不能點也不能打字；滑鼠移上去說明「這個列印檔鎖定了「樣式」，要修改請先解除鎖定。」之類的原因，其他部分照常使用，也照常列印。
- 預覽上方有一行提示，例如「這個列印檔鎖定了「樣式」「版面」；要修改請按「解除鎖定…」。」（依「內容」「資料來源」「附加文字」「樣式」「版面」的順序列出實際鎖住的部分），旁邊是「解除鎖定…」按鈕。
- 按「解除鎖定…」，在「輸入列印檔密碼」視窗輸入「列印檔密碼」按「確定」；密碼錯誤時說明「密碼不正確，請再試一次」，視窗不關，次數不限。密碼正確後，這次開啟期間可以修改鎖住的部分，提示改成「已解除這個列印檔的鎖定；存檔時鎖仍會保留。」，按鈕換成「重新鎖定」。
- **解除只在這次開啟期間有效**：按「重新鎖定」、開啟別的列印檔，或關閉程式後再打開這個列印檔，又是鎖定的。
- **存回時鎖會保留**：改了沒鎖的部分（或解除鎖定後改了鎖住的部分）再存回去，用 Ctrl+S，或關閉前問要不要儲存時按「儲存」，鎖與密碼都原樣寫回。
- **另存**：還鎖著時，「儲存列印檔」視窗只顯示目前的鎖，說明「這個列印檔已鎖定，要改鎖的範圍或密碼請先解除鎖定。」，鎖原樣跟著另存的那一份走。解除鎖定後，可以改鎖的範圍、改密碼（兩個密碼欄都留空白時沿用原本的密碼），或取消「鎖定後分享給別人」把鎖拿掉。
- **設鎖的人**存檔之後，這次開啟期間仍是解除鎖定的狀態，不必馬上輸入剛設的密碼；重新開啟這個列印檔才是鎖定的。
- **鎖壞掉的列印檔**（記錄的鎖不完整）不會害列印檔打不開：程式當作沒有鎖開啟，狀態列說明「這個列印檔的鎖不完整，已當作沒有鎖開啟。」，存檔後這個壞掉的鎖就不再存在。

### 有鎖的列印檔不記到程式設定

開著有鎖的列印檔時（不論有沒有解除鎖定），`settings.json` 裡的設計、版面、欄位對應、張數、份數、資料來源與輸出設定，維持打開這個列印檔之前的值；主題、目前的版面（E 或 C）、紙張預設等程式本身的設定照常儲存。
下次直接開啟程式（不是雙擊列印檔），畫面回到打開列印檔之前的樣子；打開沒有鎖的列印檔後，恢復原本的記憶方式。自己設鎖並存檔時也一樣：從設鎖那一刻起，之後的修改不會記到程式設定，要保留請存回列印檔。

## 快捷鍵

| 按鍵 | 動作 |
|------|------|
| Ctrl+S | 儲存列印檔：已經開著列印檔就直接存回去，沒有就問要存到哪裡 |
| Ctrl+Shift+S | 另存列印檔 |
| Ctrl+O | 開啟列印檔 |
| Ctrl+P | 列印：和「檔案」標籤的「列印」相同 |
| Ctrl+C | 複製預覽圖；游標在文字框裡時照常複製文字 |
| Ctrl+E | 批次匯出：和「開始匯出…」相同 |
| F1 | 開啟說明 |

- 快捷鍵做的事和畫面上對應的按鈕完全相同；按鈕不能按時，快捷鍵也不做事，狀態列會說明原因。
- Ctrl+O 開啟的是**列印檔**，不是資料檔（資料檔在「資料」標籤開啟）。Ctrl+P 直接列印，和按「列印」一樣，不先開預覽列印。
- Ctrl+S 存回已經開著的列印檔時，鎖與密碼原樣保留；Ctrl+Shift+S 與還沒有列印檔時的 Ctrl+S，會先出現「儲存列印檔」視窗（見〈列印檔的鎖〉）。
- 輸入列印檔密碼、儲存列印檔、預覽列印，或詢問要不要儲存的視窗開著時，只有 F1 有作用。

## 儲存位置

設定與範本放在 `%APPDATA%\QRBarcodeStudioRS\`（名稱加 RS，避免和舊版混用）；「設定」頁的「設定檔位置」會顯示這個資料夾，並有「開啟資料夾」按鈕。

| 路徑 | 內容 |
|------|------|
| `settings.json` | 設定：目前的版面（E 或 C）、主題、上次的產生參數、最近的資料檔、紙張預設；開著有鎖的列印檔時，產生參數維持打開之前的值（見〈列印檔的鎖〉） |
| `templates\` | 範本，每個範本一個 `.json` 檔 |
| `window.ron` | 視窗位置與大小 |
| `instance.lock` | 先開的視窗開著的鎖檔：拿不到它的視窗（第二個視窗）不儲存設定，見〈安裝〉；程式結束時放開，檔案本身沒有內容 |
| `settings.json.bad` | 設定檔損毀或讀不到時留下的備份；已經有這個檔案時，檔名另外加上日期時間（`settings.json.<yyyyMMdd-HHmmss>.bad`），舊的備份不會被蓋掉 |

寫入設定時先寫成 `.tmp` 再改名，避免寫到一半當機而損毀；讀取失敗時把舊檔改名成 `.bad` 保留，再用預設值啟動並在狀態列說明。

## 忘記列印檔密碼

列印檔只存密碼的雜湊值，忘記了也查不回來。程式裡的說明只寫「請參考 README」，做法在這裡：

忘記密碼時：關閉程式，用記事本開啟 .qrbjob，刪除 "lock" 那一段（從 `"lock": {` 到對應的 `}`，注意前一行結尾的逗號）後存檔。

具體來說，`"lock"` 是檔案最後一段，長得像下面這樣；刪掉從 `"lock": {` 到它對應的 `}` 的所有行，再把前一行（`"print"` 那一段的 `}`）結尾的逗號拿掉，讓檔案仍是正確的 JSON：

```json
  "print": {
    ...
  },
  "lock": {
    "parts": [
      "layout",
      "style"
    ],
    "password": "$argon2id$..."
  }
}
```

存檔後再用程式開啟這個列印檔，就是沒有鎖的列印檔，其他內容都不受影響。這是防止誤改的鎖，不是資安防護，所以拿掉它不需要任何工具；只改一份就拿掉那一份的鎖，其他有鎖的列印檔不受影響。

## Excel 注意事項

Excel 的數字格式會把開頭的 0 去掉（例如 00123 變成 123），請先把那一欄設成文字格式再存檔。

## 與舊版的差異

- **會保存設定**：兩個舊版都不保存任何設定，Rust 版記住版面、參數、視窗位置與最近的資料檔，另可存具名範本；設定檔損毀時改名成 `.bad` 保留，不會默默重設。
- **畫面不卡**：預覽在背景產生並防抖；批次匯出在背景執行，有進度、可以取消，不再每打一個字就在介面執行緒重畫。
- **尺寸正確**：模組對齊整數個點，不再用縮放造成灰階邊緣，指定寬與高時也不會把圖拉伸；PDF 頁面依 mm 設定（Python 版的頁面尺寸曾錯成約 4 倍）；列印不再放大填滿紙張，印出來的實際大小等於設定的 mm。
- **檔案格式**：WebP 是真的 WebP（Python 版寫出的是 PNG）；EPS 直接輸出向量，不再依賴 Inkscape；每種格式有各自的編碼器，並且都畫出附加文字與 Logo；不再輸出 XAML。
- **內容正確**：Wi-Fi、mailto、vCard 與日曆事件的特殊字元都會跳脫；QR 的附加文字不再一律寫進編碼內容，改為選項（預設關閉）；條碼內容輸入時就檢查。
- **資料**：Excel 不再出現 `1234.0`、`nan`（前導零的處理見〈Excel 注意事項〉）；Excel 開著時讀得到；Big5 的 CSV 不再亂碼，欄位內換行不會被拆壞；序號規則可以前後綴為空、可設間隔、起點大於終點時明確報錯；輸出範圍在不同資料來源間各自記錄；批次與列印用的是目前載入的清單。
- **批次**：同名檔案不會靜默覆蓋；單筆失敗不會讓整批停止；有失敗清單可以匯出。
- **說明**：說明內容從程式本身產生，修正了舊說明與實際行為不符的地方（例如條碼類型的數量、建議的靜區寬度、QR 版本「自動」的意思）。
- **介面**：使用原生視窗外框，可以貼齊螢幕邊緣，最大化不會蓋住工作列；有快捷鍵，所有捲動區都能用滑鼠滾輪；錯誤訊息改寫成「發生什麼事＋怎麼處理」的句子；介面上的每個設定都真的有作用。
- **這一版不做**：掃描與解碼條碼、XAML 輸出，以及 macOS／Linux。
